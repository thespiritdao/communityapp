# Events & Community Calendar Guide

## What are Events in SpiritDAO?

Events are community gatherings with blockchain-based registration:
- **On-chain Registration**: NFT-based event tickets
- **Attendance Tracking**: QR code check-in system
- **Completion NFTs**: Proof of attendance
- **Pod-Specific or Public**: Events can be restricted
- **Token-Gated**: Require specific tokens to register

---

## Event Types

### Public Events
- Open to all DAO members
- No special requirements
- Visible in main calendar
- Examples: Town halls, social mixers

### Pod Events
- Restricted to pod members
- Require pod membership
- Pod-specific calendar
- Examples: Team meetings, workshops

### Token-Gated Events
- Require specific token/NFT
- Set by event creator
- Can combine with pod restriction
- Examples: Holder-only events

### Paid Events
- Registration fee required
- Priced in **$SYSTEM**, **$SELF**, both, or free
- $SYSTEM covers event costs (refundable if canceled)
- $SELF tickets are paid by **burning $SELF** (see below)

### $SELF-Priced Events
- Pay by **burning** your $SELF participation token
- $SELF is soulbound: it can only be earned and burned, never transferred
- A great way to **spend $SELF before it fades** (~6 months after earning)
- Burning mints you a soulbound ticket/receipt, checked at the door

## Registering for Events

### Check Eligibility
**Requirements May Include:**
- Pod membership
- Token holdings
- NFT ownership
- Registration fee
- Available capacity

**How to Check:**
- View event details
- See "Requirements" section
- Green checkmark = you qualify
- Red X = you don't meet requirement

### Registration Steps

**Step 1: Click "Register Now"**
- On event details page
- Must meet all requirements
- May require wallet interaction

**Step 2: Review Details**
- Confirm date and time
- Check location
- Note any special instructions

**Step 3: Pay Fee (if required)**
- **$SYSTEM events:** approve token spending, then register
- **$SELF events:** confirm the **burn**; the required $SELF is burned from your balance (never transferred)
- Registration is always **gasless** via your Smart Wallet, so you only pay the event's token fee, if any

**Step 4: Mint Registration NFT**
- Transaction creates your ticket NFT
- For $SELF events, this is a **soulbound ticket/receipt** minted from your burn
- Unique token for this event
- Stored in your wallet
- Proof of registration, scanned at door via QR check-in

**Step 5: Confirmation**
- Receive notification
- Event shows "Registered" status
- NFT visible in wallet
- Can view in Identity page

![Registering: choose $SELF or $SYSTEM for paid events.](https://app.spiritdao.org/images/docs/events/03-register-modal.png)

### After Registration
- Add to your calendar (iCal/Google)
- Receive reminder notifications
- Can view QR code for check-in
- See other registered attendees

## Attending Events

### Before Event

**24 Hours Before:**
- Receive reminder notification
- Check event details again
- Note location/link
- Prepare any materials

**Day Of:**
- Another reminder sent
- Check-in window opens
- QR code becomes active

### Check-In Process

**Virtual Events:**
1. Join meeting link
2. Event host marks attendance
3. Or use QR code in video
4. Attendance recorded on-chain

**Physical Events:**
1. Go to event location
2. Show QR code to organizer
3. They scan your code
4. Check-in confirmed
5. Or self-check-in if enabled

**QR Code:**
- View in event details
- Or in notifications
- Unique to you and event
- Valid only during event window

![Your check-in QR code.](https://app.spiritdao.org/images/docs/events/04-checkin-qr.png)

### During Event
- Participate actively
- Network with attendees
- Take notes
- Provide feedback if requested

### After Event

**If Attended:**
- **Event Completion Certificate** minted: a soulbound token (accreditation)
- Earned by checked-in attendees after the event completes
- Added to your collection as permanent proof of attendance
- May unlock rewards

**If Missed:**
- Registration NFT remains
- No completion NFT
- May be marked no-show
- Can explain if issue occurred

## Creating Events

**Required:**
- Be pod leader (for pod events) OR
- Have event creation permission OR
- Have executive pod access

### Step 1: Navigate to Create Event
1. Go to **Events** page
2. Click "Create Event" button
3. Or through pod management

### Step 2: Fill Event Details

**Title:**
- Clear, descriptive name
- 50 characters or less
- Example: "Monthly Community Call #5"

**Description:**
- What is the event about?
- Agenda or topics
- Who should attend?
- What to bring/prepare
- Use Markdown formatting

**Date & Time:**
- Start date and time
- End date and time
- Timezone (auto-detected)
- Consider attendee locations

**Location:**
- Physical address OR
- Virtual meeting link
- Add access instructions
- Include parking/entry info

**Image:**
- Event banner/flyer
- Recommended: 1200x628px
- Eye-catching design
- Brand aligned

**Capacity:**
- Maximum attendees
- Leave blank for unlimited
- First-come-first-served
- Can increase later if needed

![Create an event: title, date, location, capacity, price.](https://app.spiritdao.org/images/docs/events/05-create-event.png)

### Step 3: Configure Registration

**Registration Fee:**
- Free (no cost)
- Or price in **$SYSTEM**, **$SELF**, or both
- $SYSTEM covers event costs; $SELF tickets are paid by **burning** the attendee's $SELF
- Pricing in $SELF gives members a place to spend participation before it fades
- Encourage commitment

**Token Gating:**
- Require specific token
- Set minimum balance
- Example: "5 USDC minimum"

**NFT Gating:**
- Require specific NFT
- Example: "Advocate required"

**Pod Restriction:**
- Limit to pod members
- Or open to all DAO
- Can combine with token gating

**Approval Required:**
- Manual approval by creator
- Review each registration
- Or auto-approve if criteria met

### Step 4: Advanced Settings

**Check-In Settings:**
- Enable/disable check-in
- Set check-in window
- Allow self-check-in
- QR code vs. manual

**Completion NFT:**
- Auto-mint for attendees
- NFT metadata (name, image)
- Only for those who checked in
- Proof of attendance

**Notifications:**
- Reminder timing (24h, 1h before)
- Announcement to followers
- Post in forum
- Share in pod chat

**Privacy:**
- Show attendee list publicly
- Or hide until registered
- Private vs. public event

### Step 5: Review and Create
1. Preview event page
2. Double-check all details
3. Click "Create Event"
4. Sign transaction
5. Event goes live immediately

## Managing Your Events

### As Event Organizer

**Monitor Registrations:**
1. Go to event details
2. See "Registrations" tab
3. View all registered attendees
4. Check payment status
5. See total count

**Edit Event:**
- Update details anytime
- Change date/time (notify attendees)
- Adjust capacity
- Modify requirements

**Approve Registrations:**
- If approval required
- Review each applicant
- Approve or reject
- Provide reason if rejecting

**Check In Attendees:**

**Manual Check-In:**
1. Go to event page
2. Click "Check-In Management"
3. See attendee list
4. Click "Check In" next to name
5. Confirms their attendance

**QR Code Scanning:**
1. Use phone/tablet
2. Open camera
3. Scan attendee's QR code
4. System auto-checks them in
5. Confirmation shown

**Self-Check-In:**
- Attendees check themselves in
- Enter code or scan QR at venue
- Less organizer work
- Trust-based system

**After Event:**
- Mark event as completed
- Mint completion NFTs
- Thank attendees
- Share photos/recap
- Gather feedback

**Cancel Event:**
- If needed, cancel early
- Refund registration fees
- Notify all registrants
- Provide reason/apology

## Best Practices

### For Event Organizers

**Plan Ahead:**
- Create events 2+ weeks in advance
- Give people time to register
- Block your own calendar
- Prepare materials early

**Clear Communication:**
- Detailed description
- Specific location/link
- Clear requirements
- Answer questions promptly

**Manage Capacity:**
- Set realistic limits
- Consider venue size
- Factor in no-shows (10-20%)
- Can always increase

**Follow Up:**
- Thank attendees after
- Share takeaways
- Post photos/recording
- Gather feedback

### For Event Attendees

**Register Early:**
- Popular events fill up
- Secure your spot
- Add to calendar
- Don't procrastinate

**Respect RSVP:**
- Only register if you'll attend
- Cancel if plans change
- No-shows hurt organizers
- Build good reputation

**Arrive Prepared:**
- Read event details
- Bring required items
- Arrive on time
- Have QR code ready

**Engage Actively:**
- Participate in discussions
- Network with others
- Ask questions
- Contribute value

## Common Scenarios

### "Can't Register for Event"
**Possible Causes:**
- Don't meet requirements
- Event at capacity
- Registration closed
- Not in required pod

**Solutions:**
- Check eligibility requirements
- Join waitlist if available
- Contact organizer
- Join required pod first

### "Missed Event Check-In"
**What to Do:**
- Contact organizer immediately
- Explain situation
- Provide proof you attended
- Request manual check-in
- Be honest about lateness

### "Event Canceled"
**You Will:**
- Receive notification
- Get automatic refund (if paid)
- Keep registration NFT (as memorabilia)
- See updated calendar

### "Wrong Date/Time"
**Double Check:**
- Event timezone vs. yours
- Calendar app settings
- Daylight saving time
- Organizer's location

## Troubleshooting

### QR Code Not Working
- Ensure brightness up
- Try screenshot of QR code
- Check internet connection
- Use manual check-in option
- Contact organizer

### Registration Transaction Failed
- Check wallet balance
- Verify correct network (Base)
- Try Smart Wallet option
- Increase gas limit
- Retry after 30 seconds

### NFT Not Received
- Wait 60 seconds for sync
- Check wallet on correct network
- View in Identity page
- Check transaction status
- Contact support if still missing

### Can't Find Event
- Check date filters
- Remove pod filters
- Use search function
- May be private/unlisted
- Contact event creator
