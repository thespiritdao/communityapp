# Marketplace & Shopping Guide

## What is the Marketplace?

SpiritDAO's marketplace is a community store where members can buy and sell products using cryptocurrency:
- **Crypto Payments**: Pay with $SELF or $SYSTEM tokens
- **Token-Gated Products**: Some items require specific tokens/NFTs to purchase
- **Gasless Checkout**: Use Smart Wallet for fee-free transactions
- **Pod Treasuries**: Funds can route to pod treasuries
- **Order Tracking**: View your purchase history and order status
- **Fulfillment System**: Automated notifications for order processing

---

## Marketplace Roles

### Buyer
- Anyone with connected wallet
- Browse products

- Track order history

### Product Creator
- Pod members with marketplace access
- Create product listings

- Route funds to pod treasury or personal wallet

### Order Manager

- View all orders

## Understanding Token-Gated Products

### What is Token Gating?
Some products require you to hold specific tokens or NFTs to purchase:
- **Pod Membership**: Must be member of specific pod
- **NFT Holdings**: Must hold specific NFT (e.g., Advocate NFT)
- **Token Balance**: Must hold minimum amount of specific token
- **Combination**: May require multiple tokens

### Check Eligibility
**If Token-Gated:**
1. View product details
2. See "Token Requirements" section
3. Green checkmark = you qualify
4. Red X = you don't meet requirements
5. Lists which tokens you need

**How to Qualify:**
- Join required pod
- Mint required NFT
- Purchase required tokens
- Meet minimum balance

### Accessing Token-Gated Products
- Products you don't qualify for appear grayed out
- Can view details but can't add to cart
- Shows what tokens you need
- Once qualified, can purchase immediately

## Checkout Process

### Step 1: Review Cart
1. Open cart
2. Verify all items correct
3. Check sizes and quantities
4. Review total price

### Step 2: Select Payment Token
**Choose Token:**
- $SELF - Community token
- $SYSTEM - Governance token

**Check Your Balance:**
- Balance shown at top
- Red if insufficient
- Need to acquire more tokens first

### Step 3: Complete Purchase

**Transaction Flow:**

**If Sufficient Allowance:**
- Click "Purchase" button
- Single transaction
- Approve in wallet
- Wait for confirmation

**If Needs Approval:**
- Click "Approve & Purchase" button
- Combined transaction
- Approves token spending + purchases
- Sign once in wallet
- Gasless if using Smart Wallet

**Using Smart Wallet (Recommended):**
- No gas fees
- Faster confirmation
- Cleaner experience
- Sponsored by DAO

**Using Standard Wallet:**
- May have small gas fee
- Confirm network is Base
- Ensure sufficient ETH for gas

### Step 4: Confirmation
After successful purchase:
- Cart clears automatically
- Success notification shown
- Order record created
- Fulfillment team notified
- Transaction hash provided

## Creating Products (For Sellers)

**Required:**
- Pod membership
- Marketplace access permission for that pod
- Pod must have marketplace module enabled

### Step 1: Access Product Creation
1. Go to **Marketplace** page
2. Click "Add Product" button (only visible if you have permission)
3. Product creation modal opens

### Step 2: Select Pod Context
**Choose Pod:**
- Dropdown shows pods where you have marketplace access
- Product will be associated with this pod
- Funds route based on pod settings

**Verify Permissions:**
- ✅ Marketplace Module: ON
- ✅ Marketplace Access Permission: Granted
- If no pods shown, contact pod leaders

### Step 3: Fill Product Details

**Product Title:**
- Clear, descriptive name
- 50 characters or less
- Examples:
  - "SpiritDAO Logo T-Shirt"
  - "Community Sticker Pack (5)"
  - "DAO Member Hoodie"

**Description:**
- Detailed product information
- Materials and specifications
- What's included
- Care instructions
- Use Markdown for formatting

**Product Image:**
- Click "Upload Image"
- Select image file
- Recommended: 1200x1200px
- JPG or PNG
- Max 5MB
- Shows preview

### Step 4: Set Pricing

**$SELF Price:**
- Price in $SELF tokens
- Supports up to 4 decimals
- Example: 0.5000
- Leave 0 if not accepting $SELF

**$SYSTEM Price:**
- Price in $SYSTEM tokens
- Supports up to 4 decimals
- Example: 2.0000
- Leave 0 if not accepting $SYSTEM

**Important:**
- At least one price must be greater than 0
- Buyers can choose which token to pay with
- Consider current token values
- Research comparable products

### Step 5: Inventory Settings

**Quantity:**
- How many come per order
- Usually 1 for single items
- Example: 5 for sticker packs

**Units Available:**
- Total inventory count
- How many you can sell
- Decrements with each sale
- Can update later

**Available Sizes:**
- Select all applicable sizes
- XS, S, M, L, XL, XXL, One Size
- Buyers choose during checkout
- One Size = no size selection

### Step 6: Configure Token Gating (Optional)

**Purpose:**
- Restrict who can purchase
- Reward specific members
- Create exclusive items

**Options:**

**No Token Required:**
- Open to everyone with wallet
- Requires Executive Pod membership to create
- Most accessible option

**Specific Token:**
- Require NFT ownership
- Example: "Advocate NFT required"
- Buyer must hold at time of purchase

**Pod Membership:**
- Must be member of specific pod
- Example: "Contributors Pod only"
- Token represents pod membership

**Pod Leadership:**
- Leaders of specific pod only
- Example: "Design Pod Leaders"
- Most restrictive

### Step 7: Additional Options

**Free Shipping:**
- Check box if shipping included
- Shown as badge on product
- Affects buyer decision

**SKU (Optional):**
- Internal tracking number
- Not shown to buyers
- Helps with inventory management

### Step 8: Set Fund Destination

**Creator Wallet:**
- Funds go directly to you
- Immediate receipt
- Your responsibility to manage

**Pod Treasury:**
- Funds route to pod's multi-sig wallet
- Transparent accounting
- Requires pod treasury module
- Multiple signatures for withdrawal

**Choose Wisely:**
- Pod products → Pod treasury
- Personal items → Creator wallet
- Can't change after creation

### Step 9: Create Product
1. Review all information
2. Click "Create Product"
3. Sign transaction
4. Wait for confirmation (30 seconds)
5. Product appears in marketplace
6. Available for purchase immediately

## Smart Wallet Benefits

### Gasless Transactions
**Advantages:**
- No ETH needed for gas
- Faster checkout
- Cleaner experience
- Reduced friction

**How It Works:**
- DAO sponsors gas fees
- Uses ERC-4337 (Account Abstraction)
- Bundler submits transactions
- You sign with wallet

**Setting Up:**
- Automatically offered during wallet creation
- Or add Smart Wallet in settings
- One-time setup
- Works across all features

### Traditional Wallet
**When to Use:**
- Smart Wallet unavailable
- Prefer full control
- Advanced user

**Requirements:**
- Have ETH for gas (small amount)
- On Base network
- Confirm transactions manually

## Troubleshooting

### "Can't Add to Cart"

**Possible Causes:**
- Don't meet token requirements
- Product out of stock
- Size not available
- Not logged in

**Solutions:**
- Check token gating requirements
- Acquire needed tokens
- Select different size
- Connect wallet

### "Insufficient Balance"

**Issue:**
- Not enough tokens for purchase
- Shown in red during checkout

**Solutions:**
- Acquire more tokens
- Switch to different payment token
- Remove items from cart
- Check balance in wallet

### "Transaction Failed"

**Common Causes:**
- Insufficient gas (standard wallet)
- Network congestion
- Rejected in wallet
- Contract error

**Solutions:**
- Retry transaction
- Switch to Smart Wallet
- Increase gas limit
- Wait and try again

### "Order Not Showing"

**Steps:**
- Wait 60 seconds for sync
- Refresh page
- Check transaction on BaseScan
- Verify correct wallet connected
- Contact support if persists

### "Wrong Size Ordered"

**What to Do:**
- Contact order managers immediately
- Provide order ID
- Explain error
- May exchange if not shipped

### "Product Disappeared"

**Reasons:**
- Sold out
- Removed by creator
- Token gating changed
- Delisted for issues

**Solutions:**
- Check with product creator
- Wait for restock
- Look for similar items
