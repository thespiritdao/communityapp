# Forum & Discussions Guide

## What is the Forum?

SpiritDAO's forum is a discussion platform where members can:
- **Create Threads**: Start new discussion topics
- **Post Replies**: Engage in conversations
- **Organize by Categories**: Keep discussions focused
- **Pod-Specific Forums**: Private pod discussions
- **Markdown Support**: Rich text formatting
- **Link to Governance**: Connect discussions to proposals

---

## Forum Structure

### Categories
- **General**: Open DAO-wide discussions
- **Governance**: Proposal discussions and voting
- **Pod-Specific**: Private to pod members
- **Announcements**: Official updates
- **Help**: Support and questions
- **Ideas**: Feature requests and suggestions

### Threads
- Topic-focused discussions
- Created by members
- Organized under categories
- Can be pinned (important)
- Can be locked (closed to new posts)

### Posts
- Replies within threads
- Support Markdown
- Can include links, images
- Threaded conversations
- Quotable and linkable

## Creating Threads

### Step 1: Choose Category
1. Go to **Forum** page
2. Click on appropriate category
3. Or click "New Thread" and select category

### Step 2: Write Thread

**Title:**
- Clear, specific topic
- 50 characters or less
- Descriptive and searchable
- Examples:
  - "Proposal: Increase Governance Voting Period"
  - "How do I apply for pod membership?"
  - "Idea: Community Merch Store"

**Body:**
- Detailed explanation
- Use Markdown formatting
- Include:
  - Context/background
  - Your question or idea
  - Any relevant links
  - What responses you're seeking

**Tags (Optional):**
- Add relevant tags
- Help categorization
- Make searchable
- Examples: #governance, #tech, #design

**Attachments:**
- Upload images
- Share files
- Link to external docs
- Embed videos (YouTube, etc.)

![New thread: title, formatting toolbar, body.](https://app.spiritdao.org/images/docs/forum/03-new-thread-editor.png)

### Step 3: Choose Permissions

**Public Thread:**
- Anyone in DAO can view
- Open discussion
- Max visibility

**Pod-Only Thread:**
- Restricted to pod members
- Private conversations
- Pod category required

**Leadership Only:**
- Pod leaders can view/reply
- Sensitive topics
- Decision-making

### Step 4: Post Thread
1. Review your post
2. Preview formatting
3. Click "Create Thread"
4. Thread goes live immediately
5. You're subscribed to notifications

## Posting Replies

### Reply to Thread
1. Navigate to thread
2. Read original post and replies
3. Click "Reply" button
4. Write your response
5. Click "Post Reply"

![Replying with an @mention: type @ and pick a member.](https://app.spiritdao.org/images/docs/forum/04-reply-mention.png)

1. Click "Quote" on that post
2. Original text included
3. Add your response
4. Clear context for others
5. Click "Post Reply"

## Forum Etiquette

### Do's

**Be Respectful:**
- Treat all members professionally
- Disagree with ideas, not people
- Stay constructive
- Assume good intent

**Stay On Topic:**
- Keep posts relevant to thread
- Create new thread if diverging
- Use appropriate categories
- Don't derail discussions

**Provide Value:**
- Share knowledge and experience
- Answer questions helpfully
- Give thoughtful responses
- Link to relevant resources

**Search First:**
- Check for existing threads
- Read FAQ
- Use search function
- Avoid duplicate threads

### Don'ts

**No Spam:**
- Don't post repetitive content
- No promotional links (unless relevant)
- One thread per topic
- No bumping old threads unnecessarily

**No Personal Attacks:**
- Criticize ideas, not people
- No name-calling
- No harassment
- Report abusive behavior

**No Off-Topic:**
- Stay focused on discussion
- Don't hijack threads
- Use appropriate category
- Create separate thread if needed

**No Misinformation:**
- Verify before posting
- Correct mistakes promptly
- Link to sources
- Don't spread FUD

## Forum Moderation

### Who Can Moderate?

**Pod Leaders:**
- Can moderate pod-specific forums
- Delete inappropriate posts
- Lock/unlock threads
- Pin important threads
- Ban members from pod forum

**Forum Moderators:**
- DAO-wide moderation
- Same powers across all forums
- Enforce community guidelines
- Handle reports

### Reporting Content
1. Click "Report" button on post
2. Select reason:
   - Spam
   - Harassment
   - Off-topic
   - Misinformation
   - Other (explain)
3. Submit report
4. Moderators review
5. Action taken if valid

### Moderation Actions

**Warning:**
- First offense usually
- Notification sent
- Post remains visible
- Tracked in system

**Post Deletion:**
- Removed from forum
- Author notified
- Reason provided
- May be reversed on appeal

**Thread Lock:**
- No new replies allowed
- Existing posts remain
- Used for:
  - Concluded discussions
  - Heated arguments
  - Outdated topics

**User Ban:**
- Temporary or permanent
- From pod forum or DAO forum
- Serious violations only
- Can appeal to leadership

## Advanced Forum Features

### Thread Subscriptions
**Auto-Subscribe When:**
- You create thread
- You post in thread
- You explicitly subscribe

**Notifications For:**
- New replies
- Mentions of you
- Thread status changes
- Moderation actions

**Manage Subscriptions:**
1. Go to profile settings
2. See "Forum Subscriptions"
3. Unsubscribe from threads
4. Change notification frequency

### Pinned Threads
**Purpose:**
- Keep important threads visible
- Always at top of category
- Announcements and rules
- FAQs and guides

**Who Can Pin:**
- Pod leaders (in their pod)
- Forum moderators (DAO-wide)

### Thread Templates
**For Pod Forums:**
- Predefined thread structures
- Ensure consistency
- Guide discussions
- Examples:
  - Proposal discussion template
  - Weekly update template
  - Project kickoff template

### Polls (If Enabled)
**Create Poll:**
1. Create thread as normal
2. Click "Add Poll"
3. Enter question
4. Add 2-10 options
5. Set duration
6. Allow single or multiple votes

**Vote on Poll:**
1. View poll in thread
2. Select your choice(s)
3. Click "Submit Vote"
4. See results immediately
5. Cannot change vote

**Poll Results:**
- Live vote counts
- Percentage breakdown
- Who voted (if public)
- Closes automatically at deadline

## Connecting Forum to Governance

### Proposal Discussion Threads
**Best Practice:**
1. Create forum thread first
2. Gather feedback
3. Refine proposal based on discussion
4. Link thread when creating on-chain proposal
5. Voters can see full context

**Template for Governance Threads:**
```
# Proposal: [Title]

## Summary
[One paragraph overview]

## Problem
[What needs solving]

## Solution
[Your proposal]

## Implementation
[How it will work]

## Budget (if applicable)
[Costs and funding source]

## Timeline
[When it happens]

## Discussion Questions
1. [Question 1]
2. [Question 2]

---
Please share your thoughts below!
```

### Linking to Proposals
- Include forum link in proposal
- Include proposal link in forum
- Cross-reference in both places
- Makes context accessible

## Journal Mode

Any pod forum category can be presented as a **journal** instead of a
discussion board. Permissions and storage do not change; the category reads
like a dated log:

- Entries newest first, grouped by month
- The first photo attached to an entry becomes its cover
- Author, date, and a short excerpt on each entry
- The formatting editor is on by default when you reply

Pod leaders switch a category from **Manage → Forum** (choose *Journal* when
creating it, or use the switch button on an existing category). Combine it
with a Pod Face that renames the **Forum** button to **Journal** and your
community sees that word everywhere, including the forum page heading.

Full walkthrough: [Journal and Places](19-journal-and-places.md).

## Best Practices

### For Thread Creators

**Write Good Titles:**
- Specific and descriptive
- Avoid clickbait
- Include key terms
- Make searchable

**Provide Context:**
- Don't assume knowledge
- Link to related threads
- Explain acronyms
- Give background

**Engage with Responses:**
- Reply to comments
- Thank helpful responses
- Clarify misunderstandings
- Mark best answer (if Q&A)

**Keep Updated:**
- Edit original post with updates
- Mark resolved if question
- Close thread when concluded
- Reference outcome

### For Responders

**Read Full Thread:**
- Don't just read title
- Scan existing replies
- Don't repeat others
- Add new value

**Be Helpful:**
- Answer questions fully
- Provide examples
- Link to resources
- Share experience

**Stay Constructive:**
- Critique ideas, not people
- Offer alternatives
- Explain reasoning
- Be solution-oriented

**Follow Up:**
- Check back for responses
- Answer follow-up questions
- Acknowledge corrections
- Build conversation

## Troubleshooting

### "Can't Create Thread"
- Check if you're logged in
- Verify category permissions
- Pod forum requires membership
- May be locked category

### "Can't Post Reply"
- Thread may be locked
- Check permissions
- May need specific role
- Contact moderator if issue

### "Post Not Appearing"
- May be under review
- Check spam filter
- Wait 30 seconds
- Refresh page

### "Notification Not Received"
- Check notification settings
- Verify subscribed to thread
- Check email settings
- May be delayed
