Embed SpiritDAO Chatbot on Your Website

Copy and paste the code below to embed the chatbot on any webpage.

Option 1: Full-Page Iframe

Use this for a dedicated chatbot page:

<iframe
  src="https://spiritdao.pythonanywhere.com/widget"
  width="100%"
  height="600px"
  style="border: none; border-radius: 10px;"
></iframe>

Option 2: Floating Widget (Coming Soon)

A floating chat bubble that appears in the corner of your page.

Option 3: Webflow Embed

For Webflow sites (like spiritdao.org):

  1. Add an "Embed" element to your page
  2. Paste the iframe code above
  3. Adjust height as needed (recommended: 600px minimum)
  4. Publish your site
Note: The chatbot is currently hosted at spiritdao.pythonanywhere.com. Once you configure your DreamHost subdomain (e.g., chatbot.spiritdao.org), update the URL in the embed code.

Customize the Widget

You can customize the appearance by:

  • Adjusting the iframe width and height
  • Adding custom CSS to your page
  • Contacting us for color scheme customization
