🕉️ SpiritDAO Knowledge Assistant

Welcome to the SpiritDAO academic chatbot. This AI assistant can answer questions about books and academic documents in our knowledge base.

Available Endpoints

  • /widget - Interactive chat widget
  • /api/chat - Chat API endpoint (POST)
  • /api/health - Health check
  • /embed-code - Get embedding code for your website
