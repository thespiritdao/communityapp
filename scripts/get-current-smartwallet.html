🔍 Check Your Smart Wallet Address

Go to https://app.spiritdao.org and open the browser console (F12)

Then paste this code:

// Get your Smart Wallet address
const checkSmartWallet = async () => {
  // Try to get from CDP hooks context
  const user = window.__CDP_CURRENT_USER__; // May be exposed by CDP hooks
  
  if (user?.evmSmartAccounts?.[0]) {
    console.log('✅ Smart Wallet:', user.evmSmartAccounts[0]);
    return user.evmSmartAccounts[0];
  }
  
  // Fallback: check localStorage
  const keys = Object.keys(localStorage);
  console.log('📦 LocalStorage keys:', keys);
  
  // Look for CDP-related keys
  const cdpKeys = keys.filter(k => k.includes('cdp') || k.includes('coinbase') || k.includes('wallet'));
  console.log('🔑 CDP-related keys:', cdpKeys);
  
  cdpKeys.forEach(key => {
    try {
      const value = localStorage.getItem(key);
      console.log(`${key}:`, value);
    } catch(e) {}
  });
};

checkSmartWallet();

Or check wallet in app UI:

  1. Go to https://app.spiritdao.org/executive/donations
  2. Open browser console (F12)
  3. Click "Mint $SYSTEM Tokens" button
  4. The error will show which address is being used
