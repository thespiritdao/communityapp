```
┌─────────────────────────────────────────────────────────────────┐
│  📞 Incoming call from @alex                                    │
│  [ ✅ Answer ]        [ ❌ Decline ]                            │
└─────────────────────────────────────────────────────────────────┘

This banner appears OVER any screen the user is currently on
```

---

## Chat Access

```
Pod Channels:  Only pod members can see their pod's channel
Direct Messages: Any two members can message each other
Group Chats:   Create with any combination of members
```

---

## Demo Highlights

- **Pod channels** — every pod has its own group chat automatically
- **Direct messages** — private 1:1 between any members
- **Incoming calls** — real-time call notifications across the app
- **Persistent** — conversations are saved and searchable
