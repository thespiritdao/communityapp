## Forum Access Control

```
CATEGORY ACCESS
      │
      ├── General Community ─── Any logged-in member
      │
      ├── Pod-specific ──────── Pod members only
      │                         (checked via membership)
      │
      ├── Token-gated ──────────Must hold $SYSTEM tokens
      │                         (balance checked on-chain)
      │
      └── Executive ─────────── Must hold Executive hat
                                (on-chain credential check)
```

## Demo Highlights

- **Hierarchical categories** — community-wide and pod-specific spaces
- **Access-controlled** — you only see what you're supposed to see
- **Threaded discussions** — replies stay organized per topic
- **Tied to governance** — proposals can link to forum threads for context
