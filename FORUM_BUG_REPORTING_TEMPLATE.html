🐛 Bug Reporting

Found something broken? You're helping us build a better platform! Report any bugs, errors, or unexpected behavior here.

When reporting bugs, please include:

  1. What happened: Describe the bug/error you encountered
  2. What you expected: What should have happened instead?
  3. Steps to reproduce: How can we recreate the issue?
    • Go to page X
    • Click button Y
    • See error Z
  4. Device/Browser: What are you using? (Chrome/Safari/Firefox on Desktop/Mobile)
  5. Screenshots: If possible, attach images showing the issue
  6. Wallet: What wallet are you using? (Coinbase Wallet, MetaMask, etc.)

Priority Levels:

  • 🔴 Critical: App crashes, can't login, data loss
  • 🟠 High: Feature doesn't work, blocks workflow
  • 🟡 Medium: Feature works but has issues
  • 🟢 Low: Visual glitches, typos, minor UX issues

Thank you for making SpiritDAO better! 🙏
